# 生物信息学从零到实战

> 面向零基础小白的完整生物信息学教程

## 这是什么？

这是一份系统性的生物信息学教程，从最基础的生物学知识和编程技能开始，逐步深入到各种常见的生信分析方法，最终通过高水平论文复现进行实战训练。

**你不需要任何背景知识**，只需要一台电脑和学习的热情。

## 教程特色

- **零基础友好** —— 所有概念都用通俗的比喻解释，不堆术语
- **体系完整** —— 从 DNA 是什么，到独立复现 Nature 级别论文
- **实战导向** —— 每章都有真实数据和可运行的代码
- **前沿覆盖** —— 包含单细胞、空间转录组、虚拟基因敲除等最新技术

## 学习路线

```
第1站  生物学基础（第1-2章）          ← 不懂生物就是在"盲分析"
  ↓
第2站  编程基础（第3-5章）            ← 磨好工具再上路
  ↓
第3站  通用技能（第6-8章）            ← 文件格式、质控、比对 —— 所有分析的基础
  ↓
第4站  RNA-seq 分析（第9章）          ← 最常用！论文数量最多
  ↓
第5站  选一个方向深入：
       · 肿瘤方向 → 第10章 + 第15章 + 实战二
       · 表观方向 → 第11章 + 实战五
       · 单细胞方向 → 第12章 + 实战三
       · 空间组学 → 第13章 + 实战四
  ↓
第6站  高级分析（第14-18章）          ← 调控网络、虚拟扰动、ML
  ↓
第7站  论文复现实战（第21-26章）      ← 学以致用！
```
