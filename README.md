# 生物信息学从零到实战

> 先把生物问题翻译成计算任务，再选择数据和方法。

## 这是什么？

这是一份中文生物信息学教程，从基本生物学概念、数据表示和编程出发，学习如何解释观测、预测未知结果，并把候选假说与实验验证联系起来。

**从[生信总览：两条主线](/docs/00-skill-tree.md)开始。** 总览按两条主线分别展开 DNA、调控、RNA、细胞与空间、蛋白质、药物、图像与临床层面的常见任务，说明输入、输出、基本原理和生物学含义。

| 主线 | 关心什么 | 例子 |
| --- | --- | --- |
| 从观测数据识别生物状态与变化 | 已经测到的数据说明发生了什么 | 变异、差异表达、细胞组成、空间区域 |
| 预测新对象或新条件的结果，并辅助设计 | 尚未测得的性质或响应可能是什么，下一步值得测什么 | 变异影响、细胞扰动、蛋白设计、药物与结局预测 |

两条主线都依赖可靠的生物学定义和证据。是否使用公共数据、是否做过湿实验、是否使用机器学习，都不是它们的划分标准。

## 怎样学习

先选目标任务，再补相关基础。观测组学路线可从文件格式、质控、比对走向 RNA-seq、变异、表观、单细胞和空间分析；预测设计路线先定义新对象、训练标签、输出单位和独立验证，需要时再学习对应测量。做蛋白性质预测并不要求先跑完所有 RNA-seq 流程。

当前正文重点展开第 6–13 章的观测组学分析与第 19–20 章的工程、图表；总览同时给出预测设计任务的位置。第 14–18 章和六个论文复现方向仍以提纲为主，蛋白设计、完整药物研发和图像预测尚无完整独立实战。
