# 第17章 机器学习与深度学习在生信中的应用

## 17.1 监督学习基础

- 分类问题：肿瘤亚型分类
- 回归问题：药物敏感性预测
- 常用算法：随机森林、SVM、XGBoost、LightGBM
- 交叉验证与模型评估（ROC, AUC, PR 曲线）

## 17.2 无监督学习

- 聚类：层次聚类、K-means、DBSCAN
- 降维：PCA、t-SNE、UMAP 的数学直觉
- 一致性聚类

## 17.3 特征选择与生物标志物筛选

- LASSO / Elastic Net
- Boruta 算法
- RFE（递归特征消除）
- 多组学数据整合特征选择

## 17.4 深度学习入门

- CNN：序列 motif 发现、组织病理图像分析
- RNN/LSTM：序列建模
- Transformer / Attention：蛋白质结构预测
- 变分自编码器（VAE）：数据生成与降维
- 图神经网络（GNN）：蛋白互作、药物发现

## 17.5 生物大语言模型

- 蛋白质语言模型（ESM, ProtTrans）
- DNA/RNA 语言模型（DNABERT, Enformer）
- 单细胞基础模型（scGPT, Geneformer, scFoundation）
- 应用：零样本功能预测、迁移学习
