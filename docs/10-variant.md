# 第10章 基因组变异分析

- GATK Best Practices
- GATK HaplotypeCaller
- DeepVariant（深度学习方法）

## 10.2 体细胞变异检测（Somatic）

- Mutect2
- VarScan2

- CNVkit（拷贝数变异）
- Manta / DELLY（结构变异）

- ClinVar, dbSNP, gnomAD 数据库
- 致病性预测（SIFT, PolyPhen-2, CADD）

- maftools（肿瘤突变全景图）
- 突变特征分析（Mutational Signatures / SigProfiler）
- 肿瘤突变负荷 (TMB) 与微卫星不稳定 (MSI)
